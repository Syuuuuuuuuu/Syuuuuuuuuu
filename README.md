### 📖 近期关注 & 复现

#### 🤖 Agent & 多智能体系统

2026年，Agent领域正从「单Agent可靠性」迈向「多Agent协同」的新阶段。行业焦点已转向 **「多智能体图化编排 + 长期记忆 + 可验证执行」** 三位一体的下一代基础设施。

- **AgentFugue**：通过「集体推理」实现Agent规模化扩展，多个Agent在解决复杂问题时形成临时推理链，动态切换角色，在长程任务上相比单Agent有显著提升。
- **Orchard**：微软开源统一Agent训练框架，同时支持SWE（代码生成）、GUI（界面操作）、个人助手三条训练管线，推动Agent底层基础设施标准化。
- **BOAD**：IBM研究提出的分层软件工程Agent发现方法，在SWE-bench-Verified上超越单Agent和人工设计的多Agent系统。
- **Fujitsu自进化多Agent技术**：2026年5月发布，允许AI Agent通过自主验证操作经验实现安全学习与自动进化。

#### 📚 RAG 技术演进

2026年WAIC（世界人工智能大会）上，微软、蚂蚁集团与LangChain的架构师们达成共识：**「基于纯向量检索的传统RAG已触及天花板」**。**Agentic GraphRAG（智能体化图谱RAG）** 正在成为替代传统RAG的下一代标准范式。

- **三大趋势**：Agentic RAG主流化（RAG从静态管道变为Agent驱动的动态工作流）、GraphRAG轻量化革命（LightRAG、nano-GraphRAG等变体成熟）、多模态与原生集成（RAG从纯文本扩展到图像、视频、代码）。
- **Agentic RAG 3.0**：以「1M+ Token长上下文 + Multimodal GraphRAG + Agentic Retrieval」三驾马车重塑RAG技术。
- **SPARKLE**：结构化即插即用Agentic检索策略，在域内和域外QA基准上平均提升9.17%和2.85%。
- **Gemini API**：Google扩展多模态RAG能力，支持图像与文本混合检索，在FramesQA数据集上跨语料库准确率达90.1%。

#### 💻 Vibe Coding → Agentic Engineering

2026年AI编程迎来关键转折——从对话式辅助的 **Vibe Coding** 转向自主执行的 **Agentic Engineering** 范式。

- **概念演进**：2025年2月Andrej Karpathy提出Vibe Coding；2026年Karpathy在Sequoia AI Ascent大会上正式提出 **Agentic Engineering**——让AI Agent自主完成「写代码→运行→检查结果→修正→继续」的完整循环。
- **工具生态**：三大技术路线并行——IDE原生路线（Cursor、Windsurf、GitHub Copilot）、CLI终端路线（Claude Code超5.1万GitHub Stars、Codex CLI）、全栈构建路线（Replit Agent、Bolt、Lovable）。
- **实测数据**：Claude Code在Vibe Coding场景下实现88%任务完成率和79%代码可运行率；Cursor以94%可运行率位居模板代码补全榜首。

#### 🧠 模型与框架

- **DeepSeek-V4**：2026年4月24日正式发布并开源，Pro版1.6T参数（激活49B）、Flash版284B MoE（激活13B），统一支持**1M超长上下文**。Agentic Coding评测中V4-Pro已达开源模型最佳水平，内部使用体验优于Sonnet 4.5。2026年8月V4-Pro正式版已全量上线。
- **LangGraph 1.0**：2025年10月GA，2026年已发布1.0.8及1.1版本，新增类型安全流式、类型安全invoke、Pydantic/dataclass强制转换等特性。Uber、LinkedIn、Klarna等公司在生产环境使用；LangGraph与AutoGen是2026年仅有的两个获得完整企业级认证的框架。
- **Qwen 3.8-Max**：阿里巴巴2026年8月3日发布，2.4万亿参数旗舰模型首次开源。
- **Anthropic Claude Science & MHS**：2026年8月推出Claude Science（面向科研人员，支持3D蛋白质结构渲染与药物研发）和MHS（模型硬件标准，让AI自主操作可编程科研与制造设备）。
